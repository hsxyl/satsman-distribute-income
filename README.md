## NICE NEAR NAME

Trade your NEAR account easily with NICE NEAR NAME NFT. Turn your NEAR account into an NFT and trade it in any secondary market like [paras.id](paras.id).

## Start the server

```
> cd ./server
> yarn
> yarn start
```

After you update the server code, you need to stop the server and run `yarn start` again.

Open the browser with: `http://127.0.0.1:3000` to access the app.
